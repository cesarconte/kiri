🔒 Autorizar Micrófono Local

Brave y Chrome bloquean el micrófono en redes Wi-Fi HTTP locales por seguridad, salvo que autorices la dirección del PC:

1. Abre una nueva pestaña y escribe:
brave://flags (o chrome://flags)
2. Busca: Insecure origins
3. Elige Enabled y pega la dirección:
4. Pulsa Relaunch (Reiniciar) al pie de la pantalla.
